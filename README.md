# ФОНГРОБ
Закрытые офисные прогнозы с виртуальной валютой OfficeCoin.

В каталоге проекта под Node.js 24 выполните `npm ci` и `npm run dev`. Стартовая страница доступна на http://localhost:3000. Для production выполните `npm run build`, затем `npm start`. Проверки: `npm test`, `npm run lint`, `npm run typecheck`.

Первую SQL-миграцию из supabase/migrations применяют в новой базе Supabase с установленным Auth. Локальный тест применяет её к временной базе в памяти. Этапы и состояние разработки находятся в docs.

Каталог fongrob подготовлен как корень отдельного репозитория. Для проверки Docker-образа из него выполните `docker build -t fongrob .` и `docker run --rm -p 127.0.0.1:3000:3000 fongrob`. Для будущего публичного VPS потребуется настроить домен, обратный прокси с TLS и отдельное окружение Supabase.

Кабинет использует Supabase Auth и PostgREST через прокси Next.js. Для отдельной установки задайте SUPABASE_AUTH_URL и SUPABASE_REST_URL до сборки (полные базовые URL соответствующих API без завершающего слеша). Для Supabase с API gateway задайте также NEXT_PUBLIC_SUPABASE_ANON_KEY. Локальный стенд использует порты 35432 и 35433. GoTrue должен выдавать роль authenticated, PostgREST должен проверять JWT того же издателя.

### Почта и восстановление доступа

В облачном демо письма принимает Mailpit по SMTP внутри Docker-сети (fongrob-mail:1025). Его веб-интерфейс привязан к 127.0.0.1:35434 на машине стенда. В GoTrue отключено автоподтверждение (GOTRUE_MAILER_AUTOCONFIRM=false). API_EXTERNAL_URL и GOTRUE_SITE_URL используют адрес приложения. GOTRUE_MAILER_URLPATHS_CONFIRMATION и GOTRUE_MAILER_URLPATHS_RECOVERY равны /auth/v1/verify. Для переноса на VPS задайте публичный HTTPS-адрес, SMTP-параметры почтового провайдера и разрешите два точных адреса возврата с путями /login и /reset-password в GOTRUE_URI_ALLOW_LIST.

### События и прогнозы

Откройте /line. Сотрудник предлагает событие с проверяемым условием ответа «Да». ADMIN или SUPER_ADMIN публикует событие и подтверждает результат. Сотрудник, создавший событие, получает отказ при попытке прогнозировать его. В текущем рынке коэффициент равен 1.90 для обоих исходов, ставка от 10 до 250 OC. Выигрыш включает исходную ставку. Администратор может отменить событие с обязательной причиной и возвратом ставок.

Первого администратора на локальном Docker-стенде создаёт команда `python scripts/bootstrap-admin.py employee@example.test`. Сначала она выдаёт приглашение. После регистрации и подтверждения почты повторный вызов назначает SUPER_ADMIN. При существующем SUPER_ADMIN скрипт прекращает работу. Для production этот шаг выполняет оператор с доступом к базе.

Интеграционный браузерный сценарий `python scripts/check-line.py` рассчитан на тестовый Docker-стенд с Mailpit, доступным на 35434. Он создаёт вымышленные аккаунты и события.
