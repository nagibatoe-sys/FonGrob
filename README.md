# ФОНГРОБ
Закрытые офисные прогнозы с виртуальной валютой OfficeCoin.

Платформа включает события и ставки, пари, достижения, магазин наград, сезоны, рейтинг, Зал славы и расширенный профиль. Администратор управляет пользователями, товарами, заказами, достижениями и сезонными правилами. Все операции с OfficeCoin проходят через PostgreSQL-функции и журнал кошелька.

Интерфейс оформлен как закрытая букмекерская линия: события, коэффициенты и купон собраны в одном рабочем сценарии. Базовый лаймовый акцент доступен каждому. В магазине есть два дополнительных оформления — золотое и ледяное; после покупки за OfficeCoin они сразу применяются и затем переключаются в профиле. Владение и списание проверяются на сервере. Для установки изменений базы примените все миграции командой `python3 deploy/migrate.py`.

В каталоге проекта под Node.js 24 выполните `npm ci` и `npm run dev`. Стартовая страница доступна на http://localhost:3000. Для production выполните `npm run build`, затем `npm start`. Проверки: `npm test`, `npm run lint`, `npm run typecheck`.

Первую SQL-миграцию из supabase/migrations применяют в новой базе Supabase с установленным Auth. Локальный тест применяет её к временной базе в памяти. Этапы и состояние разработки находятся в docs.

Каталог fongrob подготовлен как корень отдельного репозитория. Для проверки Docker-образа из него выполните `docker build -t fongrob .` и `docker run --rm -p 127.0.0.1:3000:3000 fongrob`. Для будущего публичного VPS потребуется настроить домен, обратный прокси с TLS и отдельное окружение Supabase.

Кабинет использует Supabase Auth и PostgREST через прокси Next.js. Для отдельной установки задайте SUPABASE_AUTH_URL и SUPABASE_REST_URL до сборки (полные базовые URL соответствующих API без завершающего слеша). Для Supabase с API gateway задайте также NEXT_PUBLIC_SUPABASE_ANON_KEY. Локальный стенд использует порты 35432 и 35433. GoTrue должен выдавать роль authenticated, PostgREST должен проверять JWT того же издателя.

### Учётные записи

В VPS-конфигурации публичная регистрация выключена. Администратор создаёт пользователей командой `python3 deploy/create-user.py логин --name 'Имя'`; первого администратора — с `--super-admin`. Пароль вводится скрыто, SMTP не нужен. Подробности — в `deploy/README.md`. Старый локальный стенд с Mailpit относится к раннему демо и не используется для VPS.

После входа ADMIN или SUPER_ADMIN откройте в профиле раздел «Пользователи». Там есть список с поиском и форма создания сотрудника: логин, отображаемое имя и пароль от 5 символов. Для создания через веб-интерфейс серверу Next.js нужен `JWT_SECRET`, совпадающий с секретом GoTrue и PostgREST. Docker Compose передаёт его приложению из `deploy/.env`; при локальном `npm run dev` сервер читает этот файл напрямую. Пароль не отображается в списке и не возвращается из API.

В профиле администратора также доступны «Ставки и пари» (открытые события и ставки без результата) и «История». В истории вкладка «Прошедшие игры» показывает рассчитанные и отменённые события, а вкладка «Логи» — последние 200 операций OfficeCoin. Эти сведения доступны только ADMIN и SUPER_ADMIN.

### События и прогнозы

Откройте /line. Сотрудник предлагает событие с проверяемым условием ответа «Да». ADMIN или SUPER_ADMIN публикует событие и подтверждает результат. Сотрудник, создавший событие, получает отказ при попытке прогнозировать его. В текущем рынке коэффициент равен 1.90 для обоих исходов, ставка от 10 до 250 OC. Выигрыш включает исходную ставку. Администратор может отменить событие с обязательной причиной и возвратом ставок.

### Пари без ставок OfficeCoin

Раздел `/pari` содержит пари с ответами «Да / Нет», собственными вариантами или свободным текстом. На `/pari/new` участник настраивает условия, дедлайн и видимость ответов, проверяет результат в живом предпросмотре и публикует пари. Предпросмотр не отправляет реальный ответ. После публикации на странице пари участник может ответить один раз; чужие ответы скрываются до дедлайна, если это выбрал создатель. После дедлайна создатель вручную фиксирует результат. Для установки обновите базу командой `python3 deploy/migrate.py`. Проверка правил пари: `node --test tests/pari.test.mjs`.

Для production первого администратора создаёт оператор на VPS после миграций командой `python3 deploy/create-user.py admin --name 'Администратор' --super-admin`.

### Десктоп

Electron-клиент открывает тот же защищённый сервер и использует общие учётные записи и данные. Для локальной разработки: `FONGROB_DESKTOP_URL=http://127.0.0.1:3000 npm run desktop:dev` при запущенном `npm run dev`. Для сборки установщика Windows: `npm run desktop:build:win`; результат — `dist-desktop/FonGrob-1.0.1-x64-Setup.exe`. Переносимый EXE: `npm run desktop:build:portable`, результат — `dist-desktop/FonGrob-1.0.1-x64-Portable.exe`. Для NSIS-сборки на Linux нужен работающий Wine с поддержкой 32-битных приложений; Windows-хост может собрать установщик напрямую. Адрес сервера и уведомления настраиваются из меню приложения и на экране отсутствия связи. Для работы Desktop нужен доступный HTTPS-сервер с развернутой веб-версией и API; сама сборка сервера не содержит. Инструкции по установке сервера и сезонному обработчику — в `deploy/README.md`.

Интеграционный браузерный сценарий `python scripts/check-line.py` рассчитан на тестовый Docker-стенд с Mailpit, доступным на 35434. Он создаёт вымышленные аккаунты и события.
