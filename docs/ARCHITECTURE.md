# Архитектура
Next.js App Router обслуживает интерфейс и HTTP API одним Node.js-процессом. GET /api/health проверяет доступность процесса. Целевая БД — PostgreSQL в Supabase, идентификатор профиля совпадает с auth.users.id. Права чтения ограничены RLS. При реализации купона операции с балансом и журналом будут выполняться одной транзакцией PostgreSQL через RPC. Realtime будет доставлять клиентам изменения опубликованных событий.
