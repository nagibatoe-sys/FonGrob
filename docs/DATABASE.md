# Начальная схема
Отдел объединяет профили сотрудников. Профиль связан с пользователем Supabase Auth по первичному ключу UUID. Один профиль может иметь один кошелёк. Баланс хранится с точностью до сотых OC. Миграция задаёт нулевой баланс по умолчанию. Стартовое начисление предстоит реализовать отдельной операцией с записью в журнал.

Политику чтения своего профиля и кошелька получает роль authenticated. Для справочника отделов доступ будет определён при реализации профилей. Следующая миграция добавит приглашения, роли, права и журнал операций.
