# Расширение платформы: аудит и технический план

## Текущее состояние

Next.js 16 обслуживает веб-интерфейс; Supabase Auth и PostgREST работают с PostgreSQL. Ставки, кошелёк и неизменяемый журнал транзакций уже существуют. Все денежные операции в виртуальных OfficeCoin выполняются SQL-функциями. Профиль, админ-панель и пари добавлены ранее. У проекта нет фонового обработчика сезонов и десктопной оболочки.

## Решения

1. Магазин: каталог и остатки в PostgreSQL; покупка, отмена и возврат через транзакционные security-definer RPC с ключом идемпотентности. Никаких платежей или вывода валюты.
2. Достижения: определения и выдачи в базе; прогресс основан на ставках, профилях и сезонных результатах. Уникальные ограничения предотвращают повторную награду. Администратор меняет только допустимые правила.
3. Сезоны: календарные месяцы по умолчанию; данные ставок остаются общими, сезонные показатели вычисляются по датам. Фоновый процесс закрывает периоды; запросы тоже проверяют границу для локального режима.
4. Рейтинг и Зал славы: вычисления из ставок и зафиксированных победителей; чужой публичный профиль открывается только с разрешения владельца.
5. Desktop: Electron загружает тот же HTTPS-сервер; отдельная БД не создаётся. Настройки и окно сохраняются локально. Windows-сборка через electron-builder/NSIS, macOS и Linux возможны позднее.

## Порядок внедрения

Миграции и SQL-инварианты → тесты → страницы профиля, сезонов, достижений, магазина, рейтинга и Зала славы → админские операции → навигация → Electron → сборка и проверка.
