# Комплект передачи в Codex
1. Распакуйте архив в отдельную папку внутри репозитория, например design/pari/.
2. Передайте Codex содержимое PROMPT.md и укажите пути к prototype.html и screenshots/.
3. Откройте prototype.html в браузере для ручного сравнения. Интернет и зависимости не нужны. Для переключения используйте карточки форматов и переключатель скрытых ответов.

Скриншоты: binary — Да/Нет; multi — варианты; free — свободный ответ; visible — скрытие выключено; mobile — адаптивное состояние. Все получены из HTML, а не сгенерированы отдельно.

Проверка HTML: Playwright/Chromium — PASS: выбор форматов, отправка бинарного и свободного ответа, повторное редактирование демо-ответа, переключатель, добавление/удаление вариантов, блокировка пустого варианта, создание в демо, сброс, недопустимый дедлайн, отсутствие JS-ошибок и горизонтального скролла на 390 px. Это не тесты существующего проекта или серверной части. Верхняя навигация в HTML — визуальные подписи, маршруты должен подключить Codex. Данные HTML сбрасываются при перезагрузке. Даты и тексты демонстрационные.
