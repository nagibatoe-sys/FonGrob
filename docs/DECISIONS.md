# Решения
Для переноса на VPS используем стандартный Node.js runtime. Секреты Supabase будут задаваться при подключении авторизации. Начальная миграция закрывает клиентскую запись во все три таблицы. Для изолированной проверки SQL используем PostgreSQL в PGlite с минимальной схемой auth.

Одноразовое приглашение привязано к адресу и действительно семь дней. Право выдачи первоначально предоставлено ADMIN и SUPER_ADMIN. Регистрация блокирует строку приглашения и атомарно создаёт профиль, роль PLAYER, кошелёк и запись opening. Размер начисления хранится в economy_settings. Ошибка в любом шаге отменяет регистрацию.

Начальный рынок использует два исхода Да/Нет с фиксированным коэффициентом 1.90. Время приёма проверяет база. Проигрыш не создаёт дополнительного списания, выигрыш возвращает ставку вместе с выигрышем. Отмена возвращает исходную ставку. Операции выполняются в транзакциях с блокировками. Взаимоблокировка конкурентного приёма и расчёта может отменить один запрос, клиент показывает ошибку и позволяет повторить.
