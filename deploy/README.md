# Развёртывание сервера ФОНГРОБ

Состав — Node.js, PostgreSQL 17, Supabase Auth, PostgREST и Caddy с автоматическим HTTPS. База и служебные API доступны внутри Docker-сети. Приложение дополнительно доступно оператору на loopback-порту 3000.

Нужны Docker Engine с Compose v2, Python 3, домен с DNS-записями на VPS и SMTP-провайдер. Перед установкой проверьте действующие службы и занятые порты. Caddy использует 80 и 443.

## Первая установка

Из корня проекта выполните `python3 deploy/prepare.py`. Скрипт создаёт deploy/.env один раз и генерирует три отдельных секрета. Заполните DOMAIN, PUBLIC_URL и SMTP-параметры. PUBLIC_URL должен быть https://ваш-домен. В значениях Compose символ доллара экранируется как $$.

```
docker compose --env-file deploy/.env -f deploy/compose.yml up -d --build db auth rest app
python3 deploy/migrate.py
docker compose --env-file deploy/.env -f deploy/compose.yml --profile https up -d proxy
curl --fail https://ваш-домен/api/health
```

Мигратор ждёт таблицы Supabase Auth, применяет SQL по порядку и фиксирует контрольные суммы. Повторный запуск пропускает выполненные миграции. Изменённая применённая миграция останавливает выполнение. Демонстрационный seed автоматически не загружается.

## Обновление и копии

Перед обновлением выполните `deploy/backup.sh` и отдельно сохраните deploy/.env в защищённое хранилище. Дамп содержит учётные записи, профили, события и кошельки. Расписание и выгрузку за пределы VPS оператор настраивает при установке. Копия на том же диске не защищает от потери VPS.

Обновите файлы, повторите сборку и миграции. Изменение адресов backend API требует пересборки приложения. Ротация JWT_SECRET и паролей действующей базы требует согласованного изменения служб и БД.

## Перенос облачных данных

Текущая база содержит вымышленные аккаунты и события. Для переноса сначала приостановите запись, выполните pg_dump и сохраните действующие секреты. Восстановление выполняется в отдельную пустую базу с совместимыми ролями. После восстановления проверяются права, миграции, вход и журнал кошельков. Дамп не применяется автоматически к существующей базе VPS.

## Десктоп и обновления

Комплект обеспечивает HTTP API для будущего клиента. Windows-установщик пока не собран. Текущая линия опрашивает API каждые 15 секунд. Realtime/WebSocket предстоит внедрить перед выпуском десктопной версии.
